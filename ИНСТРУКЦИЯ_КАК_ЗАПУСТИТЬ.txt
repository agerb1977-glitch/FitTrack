ЧАСТЬ 1. КАК ПРОСТО ОТКРЫТЬ ПРИЛОЖЕНИЕ (самый лёгкий способ)
------------------------------------------------------------

1. Зайди на https://github.com/agerb1977-glitch/FitTrack
2. Нажми зелёную кнопку Code → Download ZIP
3. Распакуй архив
4. Открой файл index.html двойным щелчком
5. Он откроется в браузере
6. Готово. Приложение работает.

Что можно делать прямо сейчас:
- Нажать «Регистрация»
- Ввести имя, email, пароль, пол
- Нажать «Зарегистрироваться»
- Заполнить профиль (рост, вес, возраст)
- Добавлять тренировки
- Добавлять еду
- Смотреть прогресс по калориям на главной

Данные сохраняются в браузере (localStorage).

------------------------------------------------------------
ЧАСТЬ 5. КОРОТКИЕ ОТВЕТЫ НА ВОПРОСЫ
------------------------------------------------------------

Вопрос: Где хранятся данные?
Ответ: В этой версии — в localStorage браузера. 
В полноценной версии — в MySQL (таблицы из файла database.sql).

Вопрос: Где считается норма калорий?
Ответ: В файле js/app.js, функция calculateNorm.
Используется формула Миффлина–Сан Жеора.

Вопрос: Почему localStorage, а не сразу MySQL?
Ответ: Чтобы приложение работало без установки сервера.
Структура базы данных полностью описана в sql/database.sql
и соответствует курсовой.
