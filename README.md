## Как запустить

1. Скачай или клонируй репозиторий
2. Открой файл `index.html` в браузере
3. Зарегистрируйся и пользуйся

Ничего устанавливать не нужно.

## Структура

- `index.html` — главная страница
- `css/style.css` — стили
- `js/app.js` — логика (с подробными комментариями)
- `sql/database.sql` — структура базы данных MySQL
- `ИНСТРУКЦИЯ_КАК_ЗАПУСТИТЬ.txt` — подробная инструкция

## Технологии

JavaScript, HTML, CSS (прототип с localStorage).  
Структура БД соответствует MySQL (см. sql/database.sql).
