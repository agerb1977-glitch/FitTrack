## Возможности

- регистрация, вход и выход из профиля;
- профиль с полом, возрастом, ростом, весом, активностью и целью;
- ориентировочный расчёт калорий и КБЖУ по формуле Миффлина–Сан Жеора;
- дневник силовых и кардиотренировок с историей и удалением записей;
- дневник питания: продукты, порции, приёмы пищи и автоматический расчёт пищевой ценности;
- обзор дневного питания с прогрессом по калориям, белкам, жирам и углеводам;
- адаптивная вёрстка для компьютера и телефона.

## Запуск

1. Скачайте ZIP-архив репозитория и распакуйте его либо клонируйте репозиторий.
2. Откройте `index.html` в современном браузере.
3. Зарегистрируйтесь, откройте «Профиль» и укажите свои параметры.
4. Добавляйте записи в разделах «Тренировки» и «Питание».

Сборка и установка зависимостей не требуются. Данные хранятся в `localStorage` текущего браузера и не синхронизируются между устройствами. Очистка данных браузера удалит записи.

## Структура проекта

- `index.html` — интерфейс приложения;
- `css/style.css` — оформление и адаптивная вёрстка;
- `js/app.js` — логика интерфейса, расчёты и хранение локальных данных;
- `sql/database.sql` — учебная схема базы MySQL.

## Важно о демонстрационном прототипе

Авторизация и данные реализованы только на стороне браузера, без сервера. Это прототип для демонстрации курсовой, а не безопасная система аккаунтов: не используйте реальные или повторно используемые пароли и не храните в приложении чувствительные данные. Для публикации настоящего сервиса потребуется серверная авторизация с хешированием паролей и серверная база данных. Расчёт калорий и макронутриентов является приблизительной оценкой и не заменяет консультацию специалиста.
